# Current project reports

Use this folder for new, focused implementation or acceptance reports generated from work performed in this repository. Keep current architecture, contributor rules, and living roadmaps in their dedicated folders; move dated reports to the [documentation repository](https://github.com/lakam99/voxel-godot-docs) when they become archival history.

- `story/` — story implementation phases.
- `tutorial-town/` — tutorial-town loading and live acceptance.
- `visuals/` — visual implementation and capture reviews.
