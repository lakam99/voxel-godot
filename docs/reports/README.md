# Current project reports

This path is retained as a compatibility pointer from older plans. Do not create new reports here. Put all new implementation and acceptance reports in the [documentation repository](https://github.com/lakam99/voxel-godot-docs), under the matching topic's `reports/` folder, and link them from the relevant code or plan.

- Story reports: `game-design/story/reports/` in the documentation repository.
- Tutorial-town reports: `gameplay/tutorial-town/reports/`.
- Visual reports: `art-direction/reports/`.
