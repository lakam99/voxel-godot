Include queue depth, pending age, retries, stale rejects and cancellation/drain. Attribute main-thread stages to the same frame token used by presentation/Main monitoring. Do not add worker CPU time, physics wait, and overlapping callback intervals into a fabricated frame duration.

Instrument the bounded atoms at the production owner before tuning budgets or calling N8 converged.
