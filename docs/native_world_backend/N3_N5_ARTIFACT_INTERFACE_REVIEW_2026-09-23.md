# N3/N5 terrain artifact interface review

Status: independent read-only source audit at `50b5211`, reconciled with the cap-aware pending change at `868375e`. No production cutover or Gate 5 claim.

## Contract that already lines up

[`NativeTerrainRuntimeOwner`](../../scripts/terrain/NativeTerrainRuntimeOwner.gd) exposes retained `request_collision_artifact`, `advance_collision_artifacts`, `collision_source_snapshot` and `collision_artifact_row` through [`NativeTerrainArtifactRequests`](../../scripts/terrain/NativeTerrainArtifactRequests.gd). The broker pins owner generation, source revision/epoch, cancellation epoch, demand revision and closure token. [`NativeTerrainTriangleArtifactProducer`](../../scripts/terrain/NativeTerrainTriangleArtifactProducer.gd) checks source/demand again around the async encode, emits canonical world-frame rows with content/pin identities and per-stage timing, and invalidates a row on shaping revision drift. [`NativeResidentCollisionOwner`](../../scripts/terrain/NativeResidentCollisionOwner.gd) compares each supplied row to the source's current canonical row before installation and again across physics acknowledgement; its fixture rollback/retry is not a production binding. The runtime owner stops/drains artifact requests before publisher/backend release.

## Two blockers before the real-source fixture can represent production

1. **Global shaping invalidation can force unrelated resident remesh.** The producer compares every retained row's `shapingRegistryRevision` against the backend's current **global** revision in `collision_source_snapshot()` and `collision_artifact_row()`. One newly admitted or changed remote shaping page marks all produced resident blocks stale, even when their local `pinIdentity`/`blockContentIdentity` and triangle bytes are unchanged. The broker requeues every stale block and exposes no ready complete snapshot until all have been regenerated. A generated town advancing shaping while a broad viewer is active can repeatedly restart the resident set. Before N5 binds this as physical readiness, distinguish a changed relevant block-local source pin from unrelated registry churn; preserve explicit invalidation for genuinely intersecting support/terrain changes. A focused test should build several distant blocks, change one shaping page, and prove unchanged local artifact identities stay current while the intersecting block is retried. Do not accept a cached row merely because its geometry hashes equal: owner/source revision and installed physics still need current proof.
2. **Demand and physical membership capacities disagree.** [`NativeTerrainDemandPlanner`](../../scripts/terrain/NativeTerrainDemandPlanner.gd) admits up to 32,768 desired data blocks and returns the full required mesh-block closure. The resident collision owner rejects `requiredResidentBlocks.size() > 4096` in `_validate_request()` and accepts at most 64 affected blocks per publish. Commit `868375e` made [`NativeTerrainArtifactRequests`](../../scripts/terrain/NativeTerrainArtifactRequests.gd) retain requests and report `resident_mesh_capacity_backpressure` for an over-4,096 closure; that is honest fail-closed behavior, but it cannot finish the unchanged broad closure. A real-source fixture limited to 65 blocks would miss this. Partition the required closure into deterministic bounded physical owner windows while preserving one logical revision-complete player/NPC readiness set, retained demand, retry and safe retirement; prove an over-4,096 closure can make incremental progress without dropping old physical ownership. The final readiness check must reject a missing window, not silently shrink demand.
3. **Broker idle is not closure ready.** `NativeTerrainArtifactRequests.advance()` returns `{"status":"ready", "queuedBlocks":0}` when its retained request set is empty, even if the planner still requires other mesh blocks and `collision_source_snapshot()` is pending/incomplete. The N5 binder must explicitly request every block in the pinned required closure (or retain an incremental cursor over it), and use the complete source snapshot plus physical receipt as readiness. A fixture requesting one block must assert that broker idle never releases startup movement for a larger demanded set.

## Lifecycle checks for the binder

- On source/demand change, the broker retains `_requests`, retires/cancels the old producer, drains its async ticket, and creates a new producer with a new cancellation epoch. The binder must keep old valid colliders until the replacement is acknowledged, then retire them; `collision_source_snapshot` pending is never an empty-world success.
- `NativeTerrainRuntimeOwner.stop()` drains artifact requests before releasing the backend. Stop the N5 resident owner and actor barrier in an order that leaves no callback or source query into a released N3 owner. Test cancel while async encode is active, during per-row prepare, mid-switch and during old-shape retirement; require zero workers/shapes and a retryable current demand afterward.
- `NativeResidentCollisionOwner.physical_receipt()` requires a complete source-current resident set. Use it only after production N3 source, N5 collider and Voxel Tools collision-disable cutover; a fixture `ready` result cannot stand in for Main/Continue startup readiness.
